# The beautiful game of Guessing:  

This project is an essential example of how to implement a simple guessing game in Python. Also I take the time to choose one of the things I love the most: Soccer (or Football for most of the world).  Where the user will have to guess a soccer team that already is on the predefined list of teams.

# How to play the game well it is simple:
1. Run the program by just executing the python file.
2. The program will prompt you to enter the name of a soccer team where you will see "_" spaces representing each letter of the team
3. You will also will see the number of attempts
4. You will start guessing letters one at a time
5. Each time you guess a correct letter it will be revealed in the team name the program will also inform you if the letter was correct or not
6. If you guess all the letters of the team name before running out of attempts you win
7. If you run out of attempts before guessing the team name you lose and the correct team
8. You can play again if you want to try another team :)
